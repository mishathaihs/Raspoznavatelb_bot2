# Настройка Google Sheets

1. Заполните `.env` (или `.env.example` скопируйте в `.env`):
   - `GOOGLE_SHEETS_SPREADSHEET_ID` — оставьте пустым, если таблица ещё не создана;
   - `GOOGLE_SHEETS_WORKSHEET_TITLE` — название листа, по умолчанию `Лист1`.
2. Выполните и авторизуйте OAuth для Google:
   ```bash
   python scripts/init_drive_oauth.py
   ```
3. Инициализируйте или пересоздайте таблицу:
   ```bash
   python scripts/bootstrap_project.py
   ```
   - если ID пустой или неправильный, скрипт создаст новую таблицу и подскажет новый ID;
   - при успешной генерации структура листов будет проверена/создана.
4. Если таблица создана заново, скрипт попытается обновить `.env` автоматически. Если файл отсутствует, скопируйте ID вручную в `GOOGLE_SHEETS_SPREADSHEET_ID`.
5. Дайте сервисному аккаунту (или учётке, прошедшей OAuth) права «Редактор» на таблицу, иначе получите `SpreadsheetNotFound` или 403.

После этих шагов бот стартует без ошибок `SpreadsheetNotFound` и сможет записывать строки.
