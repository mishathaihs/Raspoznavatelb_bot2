# Локальная проверка распознавания (vision)

Скрипт не требует Telegram: достаточно картинки на диске и настроенного `.env` с ключом OpenAI.

## Как запустить

1. Подготовьте файл со сканом/фото (PDF конвертируйте в изображение, удобнее всего JPG/PNG).
2. Выполните команду (пример):

```bash
python scripts/test_vision_local.py path/to/your_scan.jpg
```

Скрипт инициализирует `VisionExtractor` так же, как бот, отправит изображение в модель и выведет prettified JSON в stdout.

## Что должно получиться

Для акта/счёта с суммами вроде `701.94 / 140.39 / 842.33` ожидается JSON вида:

```json
{
  "doc_type": "act",
  "doc_number": "44/10Э",
  "doc_date": "2025-10-31",
  "supplier": "УП «РСВ» Рева С.В.",
  "customer": "ООО «Интергруз»",
  "contract_number": "44 от 31.10.2023",
  "service_month": "Октябрь 2025",
  "currency": "BYN",
  "items": [
    {
      "name": "Возмещение фактических расходов по электроэнергии",
      "quantity": 1778,
      "unit": "кВт",
      "tariff": 0.39479,
      "amount_wo_vat": 701.94,
      "vat_rate": 20,
      "vat_amount": 140.39,
      "amount_with_vat": 842.33
    }
  ],
  "total_wo_vat": 701.94,
  "total_vat": 140.39,
  "total_with_vat": 842.33
}
```

Если модель не смогла распарсить JSON, скрипт завершится ошибкой, а логи покажут сырой ответ для отладки.
